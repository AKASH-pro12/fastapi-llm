# FastAPI LLM Integration

A FastAPI application that integrates LangChain with a Groq-hosted Qwen LLM to process user questions through an HTTP API.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- LangChain
- Groq
- Qwen
- Python Dotenv

## Installation

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Environment Setup

Create a `.env` file in the project root directory:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace `your_groq_api_key` with your actual Groq API key.


## Run FastAPI

Start the FastAPI application using Uvicorn:

```bash
uvicorn main:app --reload
```

The application will run at:

```text
http://127.0.0.1:8000
```

FastAPI interactive documentation is available at:

```text
http://127.0.0.1:8000/docs
```

## API Endpoint

### POST `/ask`

Accepts a question and returns the response generated by the Qwen LLM.

### Request

```json
{
  "question": "What is LangChain?"
}
```

### Response

```json
{
  "response": "LangChain is a framework for building applications powered by language models."
}
```
